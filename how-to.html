PLAY GUIDE

Get close.
Don't cross.

The 50 Line is a basketball memory game built around NBA regular-season leaderboards. Choose an era, read the assignment, and trust your knowledge of the league.

01

Start with an era.

Choose a decade from the 1980s through the 2020s. A run uses seasons whose starting year falls inside that decade. Choosing the 2010s, for example, includes 2010–11 through 2019–20.

Every standard run contains eight randomized season-and-category assignments.

02

MODE ONE

The 50 Line

Choose one player for each assignment. Your goal is to select the player ranked closest to 50th without going beyond it.

the player's rank
#51+Bust

Eight rounds create a maximum possible score of 400.

03

MODE TWO

Triple Take

You receive one season and category, then make three unique player picks. Each rank is revealed immediately, letting you recalibrate before your next selection.

PLAYER 1 RANK+PLAYER 2 RANK+PLAYER 3 RANK=100

Get as close to 100 as possible. Exactly 100 is perfect; crossing 100 busts the entire run for zero.

04

MODE THREE

Shot Clock

The 50 Line rules, under pressure. You have 24 seconds to search for and lock in one player on every assignment. If the clock reaches zero, the pick is an automatic miss worth zero.

Eight rounds. Twenty-four seconds per pick. No extensions.

04

Stat categories

All challenges use regular-season player statistics. Counting stats use season totals; percentage and ratio categories use their calculated rate.

MINFGMFGAFG%3PM3PA3P%FTMFTAFT%OREBDREBREBASTSTLBLKTOVEFFPTSAST/TOSTL/TOVPF

EFF = PTS + REB + AST + STL + BLK − missed field goals − missed free throws − TOV. Ratio categories exclude players with zero turnovers because the ratio is undefined.

05

DATA & METHODOLOGY

Where the numbers come from

Our source statistics come from NBA.com Stats. We retrieve them with the open-source nba_api Python client, then generate compact season files stored with the website.

The browser never requests NBA.com during a game. Cached data makes play faster and keeps the site working when the upstream API is slow or temporarily unavailable. The dataset currently covers 1980–81 through 2025–26 and can be regenerated as new seasons become available.

The 1980–81 starting point ensures every category used by the game exists across the supported range. This is an independent fan project and is not affiliated with or endorsed by the NBA.

06

How rankings work

Players are sorted from the highest value to the lowest within the assigned season and category. If two players have the same value, names are sorted alphabetically to produce a stable order. The rank represents position in that complete ordered list.

Percentage categories currently include every player with a recorded value; the game does not apply NBA award-qualification minimums. This makes the rule consistent across every historical season, though low-volume players can rank unusually high in percentage categories.
